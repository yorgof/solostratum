# Security Policy

## Reporting a Vulnerability

If you discover a security or consensus bug in **solostratum** — especially anything that could lose a found block, redirect block rewards, expose RPC credentials, or crash the server — please report it privately rather than opening a public issue.

Use [GitHub Security Advisories](https://github.com/yorgof/solostratum/security/advisories/new) to submit a private report with:

- A description of the issue and its impact
- Steps to reproduce (or a test case / minimal example)
- The `solostratum` version (`./solostratum -version`) and Bitcoin Core version, if relevant

You will receive an acknowledgment as soon as possible, and we will coordinate a fix and disclosure once verified.
